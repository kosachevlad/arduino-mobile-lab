# Arduino Mobile Lab

Мобільна навчальна мінісимуляція Arduino Uno для онлайн-уроку, створена на **React і Vite**. Учні розглядають компоненти, під'єднують потенціометр до 5V, GND і A0, запускають симуляцію та спостерігають за значенням A0 і світлодіодом.

**Сайт на GitHub Pages:** https://kosachevlad.github.io/arduino-mobile-lab/

Попередня статична версія: https://arduino-mobile-lab.kosachevlad.chatgpt.site/

## Як користуватися

1. Розгляньте схеми без під'єднань і з під'єднанням.
2. Натисніть три кнопки підключення: 5V, GND та A0.
3. Перегляньте або вставте приклад коду Arduino.
4. Запустіть симуляцію та рухайте повзунок потенціометра.

Показник A0 змінюється від 0 до 1023. За значення **512 або більше** світлодіод світиться, за меншого значення — гасне. Схема, індикатор і Serial Monitor показують його стан.

## Локальний запуск

Потрібен Node.js 20.19+ або 22.12+ (рекомендовано актуальну LTS-версію).

```bash
npm install
npm run dev
```

Vite покаже локальну адресу для перегляду. Для готової збірки запустіть `npm run build`; результат з'явиться в каталозі `dist/`.

Зображення лежать у корені репозиторію й імпортуються компонентом `src/App.jsx`. GitHub Actions автоматично збирає та оновлює сайт на GitHub Pages після змін у гілці `main`.

> Це навчальна імітація. Редактор коду не компілює довільні програми для Arduino; він супроводжує демонстрацію роботи потенціометра й світлодіода.
