# Arduino Mobile Lab

Мобільна навчальна мінісимуляція Arduino Uno для онлайн-уроку. Учні розглядають компоненти, під'єднують потенціометр до 5V, GND і A0, запускають симуляцію та спостерігають за значенням A0 і світлодіодом.

**Сайт:** https://arduino-mobile-lab.kosachevlad.chatgpt.site/

## Як користуватися

1. Розгляньте схеми без під'єднань і з під'єднанням.
2. Натисніть три кнопки підключення: 5V, GND та A0.
3. Перегляньте або вставте приклад коду Arduino.
4. Запустіть симуляцію та рухайте повзунок потенціометра.

Показник A0 змінюється від 0 до 1023. За значення **512 або більше** світлодіод світиться, за меншого значення — гасне. Схема, індикатор і Serial Monitor показують його стан.

## Локальний запуск

Відкрийте `index.html` у браузері. Файли PNG мають лежати поряд із ним. Сторінка статична й не потребує встановлення бібліотек чи сервера.

> Це навчальна імітація. Редактор коду не компілює довільні програми для Arduino; він супроводжує демонстрацію роботи потенціометра й світлодіода.
